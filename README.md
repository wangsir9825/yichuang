# 译窗 YiChuang

Windows 桌面翻译工具，当前公开版本 **1.5.5 试用版**。

**普通用户：[打开 Releases 下载安装包](https://github.com/wangsir9825/yichuang/releases/tag/v1.5.5)，选择 YiChuang-Setup-1.5.5.exe 即可。**

支持中英翻译、划词取词、截图 OCR、舒展双栏与轻巧侧窗；翻译引擎可勾选显示、排序、自定义接口及本地模型。默认内置 llama.cpp，可选 Ollama。模型权重和 API Key 不随软件分发。
