# 译窗 YiChuang

Windows 桌面翻译工具，当前公开版本 **1.5.4 试用版**。

支持中英翻译、划词和截图 OCR；提供双栏/轻巧侧窗，统一翻译方向、可自定义的翻译引擎、本地 llama.cpp 与可选 Ollama。模型权重和 API Key 不随软件分发。
